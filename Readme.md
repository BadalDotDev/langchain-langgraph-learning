# LangChain and LangGraph (TypeScript)

A practical TypeScript learning repository for modern AI engineering using:

* LangChain
* LangGraph
* Groq
* TypeScript

The repository is organized chapter-by-chapter with runnable examples and exercises.

---

# Setup

## Install Dependencies

```bash
npm install
```

---

## Environment Variables

Create:

```text
.env
```

Example:

```env
GROQ_API_KEY=your_api_key_here
```

---

# Run Examples

Run chapter examples using:

```bash
npm run chapter-1 -- basic.ts
```

Example:

```bash
npm run chapter-1 -- stream.ts
```
